## Owner overrides (2026-09-26)
- **Towers (spec §3.2 over design):** buried nests are wood silhouettes at their TRUE size (height from the size fractions), each raised 18 dp per depth behind the top nest so all are visible, plus the design's walnut "+N" tag. (`TowerStackStyle.trueSize` is the only mode shipped; keep the enum so the design's peek could return.)
- **Tap policy (design frame 2.6):** tap the selected slot → cancel; tap a legal target → move; ANY other tap (including a pickable nest of the wrong colour/size) → invalid: target shakes, the lifted nest drifts back, selection cleared. Drag: released over a legal target → move; over another slot → invalid; over nothing → cancel.
- **Extra slot (design):** always appended to the bottom shelf, the row re-pitches; the layout shrinks stands/dolls when a row exceeds 4 slots (up to 6 = 4 authored + 2 extras). Max 2 per level; kept on Restart.
- **Gold:** rendering built now (per-stop gradient map), rules deferred to v1.1.
- **Soft stuck / unsolvable hint:** design 3.4 banner + glowing Undo; hint shows nothing and charges nothing.
- **Motion values:** tokens.json wins (counter bump 1.22, wobble period 400 ms, win dance 1400/120, hop 2 = 200 ms).
- **Undesigned cases** (1 or 4 shelves, 5–6-slot rows, maxSize 6 on 3 shelves) extend the design system via BoardLayout scaling, marked with a design-tagged TODO.
- Phase 1 already delivered: `render_tokens.gen.dart` (+ `render_token_types.dart`), `ui_tokens.gen.dart` (+ `ui_token_types.dart`, `NestyShadow` with inset), `nesty_icons.gen.dart`, bundled fonts (Fredoka 500/600/700, Nunito 500–800, NestySymbols), synced assets under `apps/game/assets/` (skins/<id>/skin.svg + skin.json, symbols/, board/ (15), themes/ch0N/background.svg, audio/*.wav), `package:nesty_render/svg_tools.dart`, flutter_svg + xml + flutter_soloud 4.1.7. Fredoka has no `tnum` (Q29 open).

**Layer set per height (SVG group order):** shadow · bottomMask (tinted) · bottomDetail · [symbol at runtime] · [interior rim at runtime when open] · lidMask = top_mask (tinted) · lidOverlay = face + top_detail + shine_top · bodyShine = shine_bottom (drawn last) · goldBottomMask / goldLidMask (gray-rewritten, untinted) · silhouette (shadow + masks with wood #E6C08C modulate + shines at 0.45; no detail/face).

**API (replaces the M0 interface):**
```dart
enum DollPart { full, body, lid }
enum DollSymbols { none, subtle, large }
final class DollPaintParams {   // mutable, one per component, reused every frame
  DollColor color = DollColor.red; double height = 0; double baseX = 0; double baseY = 0; // base = art (256,742)
  double lidLift = 0;            // fraction of doll HEIGHT (nest = 0.3)
  bool open = false; DollPart part = DollPart.full; DollSymbols symbols = DollSymbols.subtle; bool silhouette = false;
  double opacity = 1, scaleX = 1, scaleY = 1, rotation = 0;   // about the base point
  double shine = -1;             // complete sweep progress, -1 off
  double reveal = -1;            // circular paint wipe from (50%, 62%), -1 off
}
abstract interface class DollRenderer {
  Future<void> prepare({required Iterable<double> heights, required double devicePixelRatio});
  bool isReadyFor(double height);
  void paint(Canvas canvas, DollPaintParams p);
  void dispose();
}
```
`paint`: `save → translate(base) → rotate → scale(k·sx, k·sy)`, `drawImage` at precomputed crop offsets with prebuilt paints (one modulate ColorFilter per colour; subtle symbol = ink srcIn α 0.94; large = disc r92 #FFF8EC + 8 px ink ring + symbol 117 opaque); rim = two `drawOval` of constant unit ovals (outer (256,398,148×21) rimColor, inner (256,401,134×15) #2A1608 @0.88); reveal = silhouette then clip to constant unit circle and draw coloured; shine = skew + clipRect band over white-filtered silhouette; opacity < 1 via saveLayer only while fading. **Zero per-frame allocation.** Nest z-order: inside = host lid → guest (full) → host body; swallow = moving lid → target → moving body. `PlaceholderDollPainter` (§12.5): unit body path + head circle, radial shader per colour built once, white face, dot eyes, split line, symbol from atlas; same API. `FallbackDollRenderer` = SVG when `isReadyFor(h)` else placeholder. Fake DI env uses placeholder only (no async raster in widget tests).

**BoardLayout (pure math, shared with admin):** input `BoardShape{rows: List<List<SlotShape{id, kind: open|tower|locked|extra}>>, maxSize}` (the game adapts core state), `BoardViewport{size, padding}`. Fit: hudBottom = padding.top + 83, barTop = H − padding.bottom − 76 (142 and 734 at 390×844); reference frame 390 × 592 (y 142…734); s = min(W/390, (barTop − hudBottom)/592, 1.5), centred → at 390×844 s = 1, exact design numbers. Presets: 3 shelves [312, 498, 684] Hs 150; 2 shelves [430, 650] Hs 140; 1 shelf [540] Hs 150 and 4 shelves [250, 395, 539, 684] Hs 104 (both design-tagged TODOs). Per row: pitch = min(96, 372/n); cx = 195 + (i − (n−1)/2)·pitch; stand 90×34 (tower 90×39) while pitch ≥ 93, else width pitch − 4 with height/surface scaled; standTop = plankTop + 9 − standH; surface = standTop + 12.3. Doll heights one scale per board: h(size) = Hs·F[size]/(maxSize == 3 ? 0.66 : 1) (F = .42/.54/.66/.78/.89/1.0), tallest clamped so width h·2/3 ≤ minPitch − 4. Geometry (from NestyBoard.dc.html): pips centre y = standTop + 24 (tower + 31.9), x = cx + (k − (N−1)/2)·7.8, left = biggest, 6 px; art base 742/768; glass case top = surface − 134, locked doll base = caseTop + 123, padlock symbol centre caseTop + 116.3 (12 px ink); ice top = plankTop + 9 − 152.5 (96×160), badge 28 px at (cx + 22, iceTop + 2); "+N" tag at (cx + 21, standTop + 16); glow ring 116×52 at (cx − 58, surface − 28); hint arrow 40×50 at (cx − 20, dollTop − 58); family-counter target (W/2, padding.top + 70). Hit rect: column pitch × row band (previous plank bottom → this plank bottom), ≥ 48×48. `buriedSilhouette(depth, trueSize)` → true-size silhouette raised 18·depth (override). `iceFrame(n, n0)` = min(3, ⌊3(n0 − n)/n0⌋); frame 3 flashes before shatter. Extra slots re-pitch the bottom row (animate 300 ms).

**Performance budget:** doll layers classic DPR 3 cropped 3–6 MB (≤ 8 MB maxSize 6); symbol atlas ≈ 0.5 MB; board sprites 1–2 MB (≤ 5 MB with glass/ice); theme bg 390×844@2 ≈ 5.3 MB; audio PCM ≈ 1.1 MB → **< 25 MB GPU images**. Raster at level load ≤ 9 layers × ≤ 6 heights, ≤ 250 ms on a low-end phone (behind the route transition). Frame: UI < 6 ms, raster < 8 ms, ~150 draw calls at 15 slots, 0 allocations when idle/wobbling.

## 2. apps/game M2
Folders: `features/gameplay/bloc/` (gameplay_bloc + parts, board_effect, tap_policy), `features/gameplay/game/` (nesty_game, components/{board_component, shelf_layer, slot_component, nest_component, hint_layer, fx_layer}, timeline/{board_timeline, motion_spec, reservations, feedback_sink, combo_tracker, clips/*}), `features/gameplay/widgets/` (gameplay_hud, level_pill, family_counter, coin_pill, booster_bar, booster_button, soft_stuck_banner), `features/gameplay/overlays/` (win_overlay, confetti, out_of_moves_sheet, pause_dialog, all_levels_done), `features/gameplay/pages/gameplay_page.dart`, `features/dev/level_picker_sheet.dart`, `core/services/{audio,haptics,solver,skin}/`, `core/repository/bundled_level_repository.dart`.

**GameplayBloc** (`BaseAsyncBloc`, strict FIFO) owns `GameSession`. Events: Started(levelNumber), SlotTapped(id), DragStarted(id), DragDropped(id?), UndoPressed, RestartPressed, HintPressed, ExtraSlotPressed, SolverResultArrived(result, forMoveSeq), PauseToggled, NextLevelPressed. State (freezed): level meta (number, id, tier, chapter, reward), snapshot, selectedSlotId, status (playing|won|outOfMoves|allLevelsDone), paused, softStuck, hint, boosters (free undos left, hints, slots, canUndo, canAddSlot), effectSeq + effect. Tap policy per override. Effects (sealed `BoardEffect`): SelectionChanged(from, to, bySource), MoveApplied(MoveResult), MoveRejected(src, dst), BoardReset(snapshot, reason start|restart|undo|extraSlot, UndoResult?), HintShown(move), HintCleared. Solver futures never awaited in handleEvent; results re-enter as SolverResultArrived and are dropped if moveSeq changed. Soft-stuck after each applied move, debounced 300 ms; budgets hint 30k, soft-stuck 20k.

**Bridge (no flame_bloc):** GameplayPage owns one `NestyGame(renderer, sprites, feedbackSink, onIntent: bloc.add)`; `BlocListener(listenWhen: effectSeq changed)` → `_game.apply(effect, snapshot)`; callbacks `onFamilyLanded` (counter increments when the doll lands), `onBoardIdle`, `onWon`, `onOutOfMoves`.

**Flame tree:** `camera.viewfinder.anchor = Anchor.topLeft` (world = logical px), transparent background. BoardComponent (Tap+Drag callbacks, hit test via `BoardGeometry.slotAt`) → ShelfLayer (planks as tiled shader, stands, pips, tags, pulsing extra slot), SlotComponent per slot (glass frames + padlock, ice frames + badge, glow ring), NestComponent per visible doll incl. silhouettes (priority by row, high while flying; no re-parenting), HintLayer (arrow bounce 0.9 s ±10, precomputed dashed arc, 0.85 ring on target), FxLayer (fixed pools: dust, sparkles (pre-rendered star), 5 splash drops, glass shards, ice burst). Reconcile from newState after each batch. Drag: onDragStart → intent; onDragUpdate moves the lifted nest visually + highlights hovered column; onDragEnd → DragDropped.
